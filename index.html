Veille Technologique

Je suis activement l'actualité cybersécurité web et applicative via Google Alerts depuis Mai 2026.

Sujet de veille · BTS SIOLa sécurisation des API REST avec OAuth 2.0 et les jetons JWT : comment garantir l'authentification et l'autorisation fine des échanges de données sans exposer les identifiants des utilisateurs ?

Flux OAuth 2.0 / 2.1

Authorization Code avec PKCE : le client n'a jamais accès au mot de passe, seulement à un jeton limité.

Jetons JWT

Structure, signature, durée de vie courte et révocation : ce qui rend un jeton fiable.

Vulnérabilités

Broken Authentication (OWASP API2), fuite de jetons, CSRF et XSS.

OWASP API Security Top 10Focus API2 : Broken AuthenticationLire la source → PortSwigger Web Security AcademyLaboratoires OAuth et JWTLire la source → CERT-FR / ANSSIAlertes et avis de sécuritéLire la source → Feedly + Google AlertsCollecte et tri des flux RSSOuvrir mon Feedly →

Ma méthodologie de veille

  1. Collecte : Google Alerts m'envoie chaque jour les actualités sur OAuth 2.0 et JWT, et Feedly regroupe mes flux RSS (OWASP, PortSwigger, CERT-FR).
  2. Tri : je garde les sources officielles et récentes, je recoupe avec une seconde source et j'écarte les articles purement commerciaux.
  3. Analyse : je note l'essentiel dans une fiche de synthèse et je relie chaque information à mon sujet (PKCE, durée de vie des jetons, OWASP API2).
  4. Exploitation : j'applique ces bonnes pratiques dans mes projets, par exemple l'authentification sécurisée de Lumoura et de Lumoura SAV.

Case Study · Lumoura

Le problème

Créer une plateforme e-commerce de parfums de luxe complète et fonctionnelle, avec gestion des utilisateurs, des commandes et une interface d'administration robuste — le tout sans framework back-end, en PHP pur avec architecture MVC.

La solution

Architecture MVC maison avec routeur personnalisé, authentification sécurisée par OTP email, API REST pour l'autocomplétion d'adresse (API Adresse gouv.fr), génération de factures PDF avec mPDF, et un dashboard admin complet pour gérer produits et commandes.

Technologies utilisées

PHP 8MySQLArchitecture MVC API RESTOTP EmailmPDF PDO sécuriséJavaScriptCSS3

Difficultés rencontrées

  • Implémenter le système OTP avec expiration et renouvellement sécurisé
  • Gérer les sessions et la sécurité des requêtes SQL avec PDO
  • Intégrer mPDF pour générer des factures PDF dynamiques formatées
  • Concevoir un routeur MVC sans framework depuis zéro

Résultat final

Plateforme e-commerce 100% fonctionnelle avec catalogue produits, panier, système de commandes complet, espace client, génération de factures PDF téléchargeables et interface admin pour gérer l'ensemble du site. Projet phare du BTS SIO SLAM.
